# Сервис To-do

Учебное приложение по заданию Яндекс Практикума. Сохраняет задачи в localStorage, поддерживает добавление, удаление, копирование и редактирование с клавиатуры.

Репозиторий: https://github.com/Alexey-UI/to-do

Исходная заготовка: https://github.com/yandex-praktikum/to-do-pre

Запустите любой статический HTTP-сервер в папке проекта и откройте index.html. После удаления всех задач пустой список сохраняется. Enter завершает редактирование, Escape отменяет его. Пустые задачи не добавляются, пользовательский текст вставляется через textContent.

По инструкции курса эта работа проверяется преподавателем через Яндекс Документ и Яндекс Форму; официальной автоматической приёмки у неё нет.
